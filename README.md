## Como foi feito

O HTML reúne a apresentação pessoal, as entregas e o manifesto. O CSS define a moldura de celular e as cores de cada tema. O JavaScript controla o carrossel e grava a preferência de tema no navegador.

Nesta atualização, o pedido ao ChatGPT foi organizar o GitHub conforme o guia do aluno. A organização aproveitou a página, os textos e a arte que já faziam parte do portfólio.

## Ajustes no portfólio

Cada trabalho disponível ganhou um card com link. As três atividades que só tinham título passaram para **Entregas sem arquivo publicado**. A contagem e os botões do carrossel acompanham a quantidade de cards.

A página do Mundo SENAI vem do [repositório do evento](https://github.com/G-Infantini/mundo-senai-2026). A pasta `mundo-senai-2026/` referencia a versão apresentada no portfólio.

## Aprendizados do projeto

- Relacionar cada card ao endereço do trabalho que ele apresenta.
- Reaproveitar a estrutura de um card ao acrescentar outra entrega ao HTML.
- Guardar a escolha entre tema claro e escuro com `localStorage`.

Para executar localmente, baixe os arquivos e abra `index.html`.
